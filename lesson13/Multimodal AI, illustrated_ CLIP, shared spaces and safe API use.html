Multimodal AI, illustrated

How one model can match the words “golden retriever in a park” to an actual photo, and how to wire it up to an API without leaking your key. Press the button to watch two separate worlds merge.

The big idea: models like CLIP place words and pictures that mean the same thing close together in one shared vector space, so we can compare text with images by measuring distance.

1. What is multimodal AI?

A modality is a type of data. Multimodal AI works with more than one. Tap a modality.

2. The problem: separate rooms

Text models turn words into embeddings. Image models turn pixels into visual features. Those two outputs live in different “rooms”, so the computer can’t tell that the phrase and the photo describe the same thing.

Different rooms, different coordinate systems. Multimodal models build a bridge: one room both can enter.

3. CLIP: learning by contrast

CLIP stands for Contrastive Language-Image Pre-training. It sees millions of image and caption pairs and learns two moves: pull matching pairs together, push mismatched pairs apart. Drag the slider to “train” and watch the similarity table sharpen.

Average similarity of correct pairs (the diagonal)
Bright diagonal = each caption has found its own picture. Dim off-diagonal = wrong pairs pushed away. CLIP is a translator between pixels and words.

4. One map for everything

In a shared vector space the word “winter” isn’t inside the pixels of a snowy forest, yet the model puts them near each other because of the visual meaning. Pick a text query, or click the map to drop your own.

5. Context resolves ambiguity

Words with two meanings confuse text-only models. An image supplies context and tips the balance. Choose a word, then add an image clue.

6. Multimodal search, end to end

Three ways to search: text → image (“red running shoe”), image → text (upload a photo, get descriptions), image → image (find similar products). Below is the final-project pipeline for text → image. Pick a query and press Run.

What the vector database stores per image

Each item has an image embedding, a text description, a unique ID, a category and a URI. The image itself stays at the URI; the database holds the vector and metadata.

8. Keep your API key secret


An API key is a credential. Treat it like a password or a credit card number.


Never
✗ Hardcode a real key in a Python file
✗ Upload it to GitHub
✗ Print the full key to “test” it
Do
✓ Put it in .streamlit/secrets.toml
✓ Keep that file out of Git (.gitignore)
✓ Print only a masked version


.streamlit/secrets.toml
OPENAI_API_KEY = "your_key_here"

import streamlit as st
api_key = st.secrets["OPENAI_API_KEY"]


Try the mask (use a fake key only)

If a real key is ever exposed, revoke it in your provider’s dashboard and create a new one.







9. Tokens and cost


Embedding APIs bill by tokens. Estimate before you send lots of text. The page can only guess; in Python, tiktoken counts exactly.






≈ tokens per text (rough guess)
total tokens
estimated cost




import tiktoken

encoding = tiktoken.get_encoding("cl100k_base")
tokens = encoding.encode("A snowy forest trail during a winter morning.")
print(tokens, len(tokens))

total_tokens = 5000
price_per_million = 0.02
print((total_tokens / 1_000_000) * price_per_million)   # 0.0001


I checked OpenAI’s model page: text-embedding-3-small is listed at $0.02 per 1M input tokens (1536 dimensions by default). Prices change, so verify before you deploy.

Glossary




Modality
A type of data: text, image, audio, video.


Multimodal AI
AI that works with more than one modality.


CLIP
Contrastive Language-Image Pre-training: matches text and images.


Shared vector space
A universal map where text and images can be compared.


Query vector
Your search text turned into numbers.


URI
An address (path or link) pointing to a file.


API key
A secret credential for calling an API.


Token
A small piece of text; the unit APIs bill by.
