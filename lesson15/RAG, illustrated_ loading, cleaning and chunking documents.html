4. Loading documents


Loading brings outside information into the app: PDF, TXT, Markdown, Word documents, web pages. Try uploads, including a bad one.


Choose a file.


import streamlit as st
from doc_helper import load_document

uploaded_file = st.file_uploader(
    "Upload a PDF or text file",
    type=["pdf", "txt"]
)
if uploaded_file is not None:
    text = load_document(uploaded_file)
    if not text.strip():
        st.warning("No readable text found.")
    else:
        st.success("File uploaded successfully.")


A doc_helper module keeps file-reading logic out of the Streamlit interface. If a PDF is scanned: use OCR, ask for a text-based version, use multimodal extraction, or warn the user.







5. Cleaning lab


Raw extracted text is messy: headers, page numbers, broken lines, odd spaces. Toggle each cleaning step and watch the text change. Hidden characters are made visible: · space, → tab, ⍽ non-breaking space, ␀ null, ↵ newline.

def clean_text(text):
    text = text.replace("\x00", "")
    text = text.replace("\u00a0", " ")
    text = re.sub(r"[ \t]+", " ", text)
    text = re.sub(r"(?<!\n)\n(?=[a-z])", " ", text)
    text = re.sub(r"\n{3,}", "\n\n", text)
    return text.strip()


Don’t over-clean. Punctuation, headings, list markers, dates and labels carry meaning. Turn on the red option to see what you lose.
